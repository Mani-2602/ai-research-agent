# 🤖 Autonomous Multi-Agent Intelligence Research Engine

A production-grade, lightweight Multi-Agent orchestration framework built from scratch using LangChain and Groq cloud hardware infrastructure. This system coordinates distinct AI agent personas to automate intensive technical web indexing, data synthesis, and document compilation with zero framework dependencies.

## 📊 Live System Capabilities
* **Automated Web Indexing Agent:** Leverages low-latency search engine hooks (`Tavily API`) to scan global databases, filter noise, and parse relevant technical data parameters.
* **Context-Aware Editorial Agent:** Sifts through raw unstructured notes via high-throughput LLM computing (`openai/gpt-oss-20b`) on Groq's API pipeline.
* **Structured Output Engine:** Automatically converts fluid data into executive briefs complete with diagnostic matrices, timelines, and market outlook matrices.
